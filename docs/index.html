01 / El problema

Del acuario a un problema de búsqueda

El algoritmo trabaja con estados y acciones definidos previamente.

◉

Estado

Temperatura entera entre 18 y 32 °C.

Ejemplo: 29 °C
↕

Acciones

Subir o bajar la temperatura 1 °C por paso.

Costo por ajuste: 1
◎

Objetivo

Llegar a la temperatura objetivo de 26 °C.

Meta fija: 26 °C
02 / Representación

Cómo se construye la búsqueda

Cada temperatura es un estado (nodo). Las acciones cambian ±1 °C y cuestan 1. La meta es llegar exactamente a 26 °C.

Estado inicial29 °C
→
Estados vecinos28 °C · 30 °C
→
Estado objetivo26 °C
03 / Formulación formal

El problema definido en cinco elementos

Esta es la definición que necesita el algoritmo para buscar una solución.

S₀

Estado inicial

S₀ = T inicial. En el ejemplo: 29 °C.

◎

Prueba de meta

Se cumple cuando T = 26 °C.

↔

Acciones

Pasar a T − 1 o T + 1, dentro del modelo de 18 a 32 °C.

g

Costo acumulado

g(n) es la suma de los costos recorridos. Cada ajuste cuesta 1.

h

Heurística

h(T) = |T − 26|. Estima cuántos ajustes faltan; no supera el costo real restante.

f

Prioridad de A*

f(n) = g(n) + h(n). Combina el costo recorrido con la estimación restante.

04 / Las fórmulas

Tres valores que guían la búsqueda

Selecciona otra temperatura en la demostración: las fórmulas se recalculan con el nuevo caso.

Costo recorrido
g(n)

Cuánto ha costado llegar desde el inicio hasta el estado actual.

g = costo acumuladon = estado actual
Heurística
h(T) = |T − Tobjetivo|

Diferencia absoluta entre la temperatura actual y la temperatura objetivo.

T = temperatura actualTobjetivo = 26 °Ch(T) = grados restantes
Prioridad de A*
f(n) = g(n) + h(n)

Combina lo que ya costó el camino y lo que falta, según la estimación.

f = prioridadg = costo realh = costo estimado

Ejemplo de la heurística

h(29) = |29 − 26|
= |3| = 3
Faltan 3 ajustes para llegar a 26 °C.

Evaluación inicial de A*

g(n) = 0 · h(29) = 3
f(n) = 0 + 3 = 3
Al inicio, el costo recorrido es 0; la estimación hasta 26 °C es 3.

06 / Comparación

Tres estrategias, una misma meta

En este grafo cada movimiento cuesta 1. Por eso BFS, UCS y A* encuentran la misma ruta de costo mínimo, aunque la exploran con criterios distintos.

Complejidad y memoria

En este grafo finito, BFS recorre por niveles; UCS prioriza g(n) y A* prioriza f(n). En teoría, BFS recorre un grafo explícito en O(V + E); UCS y A* con una cola de prioridad tipo heap suelen expresarse como O((V + E) log V). La memoria general es O(V + E). V es el número de estados y E el número de conexiones. Esta demo vuelve a ordenar una lista para elegir el siguiente estado, así que no es una prueba de rendimiento; los órdenes anteriores son referencias teóricas, no mediciones de RAM física.
