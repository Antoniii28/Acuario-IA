¿Cómo encuentra una ruta la IA?

Usamos un acuario marino simulado para entender estados, acciones, costos y heurísticas. El objetivo del ejemplo es llevar la temperatura al rango ilustrativo de 24 a 26 °C con la menor cantidad de ajustes.

1. Convertimos el problema en búsqueda

Para que un algoritmo pueda resolverlo, definimos qué significa estar en una situación, qué movimientos se permiten y cuándo llegamos a la meta.

Estado

Temperatura actual

Un estado es un valor entero entre 18 y 32 °C. Por ejemplo, 29 °C.

Acciones

Ajustar 1 grado

En cada paso podemos subir o bajar 1 °C, sin salir de los límites del modelo.

Meta

Entre 24 y 26 °C

La búsqueda termina cuando la temperatura está dentro del rango objetivo, inclusive.

2. Las fórmulas, explicadas

Cada algoritmo decide qué estado explorar a continuación de una forma distinta.

Costo acumulado

g(n)

g(n) = costo desde el inicio

En este ejemplo cada ajuste cuesta 1. Si hicimos tres ajustes, el costo acumulado es g(n) = 3.

Heurística

h(n)

h(T) = max(24 − T, 0, T − 26)

Estima cuántos grados faltan para entrar al rango. Si T = 29, entonces h(29) = max(−5, 0, 3) = 3.

Prioridad A*

f(n)

f(n) = g(n) + h(n)

A* suma el costo ya recorrido y el costo estimado restante. Si g = 1 y h = 2, entonces f = 3.

¿Por qué esta heurística es válida?

Cuenta la distancia mínima en grados hasta el intervalo objetivo. Como cada acción cambia la temperatura exactamente 1 °C y cuesta 1, nunca sobreestima el costo real: es una heurística admisible. Cuando T ya está entre 24 y 26, h(T) = 0.

3. ¿Qué hace cada algoritmo?

BFS

Búsqueda en anchura

Explora primero los estados por niveles, según la cantidad de pasos. Encuentra una ruta con menos pasos cuando todas las acciones tienen el mismo costo.

UCS

Costo uniforme

Expande primero el estado con menor costo acumulado g(n). Es útil cuando las acciones pueden tener costos diferentes.

A*

Búsqueda informada

Prioriza el menor f(n) = g(n) + h(n). Usa la heurística para orientar la búsqueda hacia la meta sin sobreestimar.

5. Cómo explicarlo en la exposición

Definir

Partimos de 29 °C y fijamos la meta entre 24 y 26 °C.

Modelar

Representamos temperaturas como estados y ajustes de ±1 °C como acciones.

Calcular

Usamos g(n) para el costo acumulado, h(n) para la distancia restante y f(n) para A*.

Comparar

BFS, UCS y A* encuentran costo 3 desde 29 °C; A* aprovecha la heurística para orientar la exploración.
